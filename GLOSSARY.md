# Glossary English → Dutch

Terms for the Dutch interface (`SessyWeb/Resources/Texts.nl.resx`). Use these consistently; add a term here before
translating it a second way.

Kept in English on purpose: solver, heatmap, fit, model, horizon, arbitrage, price capture (as "behaalde prijs
(price capture)"). In tables and charts "SoC"; in running text "laadtoestand".
